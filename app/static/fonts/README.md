# Bundled fonts

All fonts here are served locally by the app (no runtime CDN) and are licensed
under the SIL Open Font License 1.1. Each family's licence text is next to it.

| Family | Files | Use | Licence |
|--------|-------|-----|---------|
| Michroma | Michroma-Regular.woff2 | brand, headings, uppercase labels (`--display`) | OFL-Michroma.txt |
| IBM Plex Sans | IBMPlexSans-Regular.woff2 (variable: wght 100-700, wdth 85-100) | body text (`--body`) | OFL-IBMPlexSans.txt |
| IBM Plex Mono | IBMPlexMono-Regular.woff2, IBMPlexMono-Medium.woff2 | numbers, IPs, ports (`--mono`) | OFL-IBMPlexMono.txt |

Source: the google/fonts repository (ofl/michroma, ofl/ibmplexsans, ofl/ibmplexmono),
converted from TTF to WOFF2 with fontTools. The font files are unmodified apart
from the container format, and are not renamed under a Reserved Font Name.
